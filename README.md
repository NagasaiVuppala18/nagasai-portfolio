# Nagasai Vuppala — Futuristic AI & Systems Portfolio

A high-performance, single-page portfolio web application built with React 19, TypeScript, Tailwind CSS, and Lucide Icons, featuring a Sci-Fi HUD aesthetic, interactive system sandboxes, and Panda AI Digital Twin.

---

## ⚡ Core Highlights

- **Sci-Fi / Futuristic HUD Dashboard**: Deep space obsidian theme, glassmorphism cards, glowing telemetry indicators, and interactive scanlines.
- **Auto-Pilot Cinematic Tour**: Automated, smooth guided journey across portfolio chapters with intelligent user-pause detection and interactive HUD controls.
- **Narrative Journey (Chrono-Log)**: Interactive evolutionary storyboard tracing computational growth from low-level C memory models to modern distributed enterprise architectures and edge AI vision.
- **Interactive Project Matrix**: Deep-dive architecture flow models and live sandboxes for 6 flagship projects (Music Listener Audio Streamer, Smart Traffic Computer Vision, Book Review MERN Aggregator, Tech Store ACID Commerce, Iris ML Classifier, and Digital Pencil Sketch Matrix Transform).
- **Technical Arsenal**: Clean core competency matrix showcasing languages, frameworks, engines, databases, and development tooling.
- **Panda AI Digital Twin**: Interactive floating HUD knowledge chatbot capable of answering architectural questions about Nagasai's projects and engineering philosophy.
- **Communication Relay**: Sci-Fi direct transmission terminal for collaboration inquiries.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide React
- **Build Tool**: Vite 8
- **Audio Engine**: Web Audio API (zero external audio dependencies)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vuppalanagasai/nagasai-portfolio.git
   cd nagasai-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

### Production Build

To generate optimized production assets:
```bash
npm run build
```
